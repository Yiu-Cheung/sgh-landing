Model releases in SGH

How to attach a model release to your files for Adobe Stock, Shutterstock and Getty / iStock.

1The key idea: each agency keeps its own copy

The same signed release has to be available to each agency. Adobe and Shutterstock keep a library of your releases on their websites. Getty does not, so SGH keeps the document for Getty.

📄
A signed model releasefor example: Pilar, beach shoot

Adobe Stock

Upload it to Adobe once

On the Adobe Stock contributor website. SGH then lists the releases you have there.

Shutterstock

Upload it to Shutterstock once

On the Shutterstock contributor website. SGH then lists your active model releases there.

Getty / iStock

Import it into SGH once

In SGH's Release Manage tab. SGH keeps the document and sends it to Getty with every upload.

Then, on each file, pick the release for each agency ↓

2For Getty: one profile per person, one release per shoot

In the Release Manage tab you create each person once. Every time they sign a release for a new shoot, you add it to their profile.

1Add the model

Release Manage → + Add model. Fill in at least the full legal name and date of birth. The model then shows as Ready.

2Import the signed release

Import existing release: choose the document (PDF, JPG or PNG, up to 7 MB), and add a purpose and the shoot date.

3Say which kind it is

Answer whether it is Getty's enhanced release or a standard release. Repeat step 2 for every new shoot.

3On each file: tick, then pick

Select the file, open the metadata tab, and find the model release section.

1
Tick "Attach Model Release"

The release lists only load once it is ticked. The first load can take up to a minute, while the ⟳ icon spins. Untick it and SGH sends no release, but keeps your picks.

2
Pick a release in every agency row

Pick one release for each person in the shot. With two people, pick both, as in the Getty row. On Adobe you can also type a title, which must match the title on Adobe exactly.

3
Several files at once

Select the files and edit them together. Your choice replaces the releases on all of them.

4
⟳ reloads a list

For example, after you upload a new release to Adobe or Shutterstock.

4When the release is attached

It depends on the agency and on Settings → Submission → Auto Submit.

If a release cannot be attached, SGH holds that file back: it is deleted from the agency's website and marked as failed in SGH, with the reason. Fix the release, then send the file again.

5If something looks wrong

Most problems come from the list not having loaded yet, or the release not being on the agency's website.

The Adobe or Shutterstock list is empty

Wait for it to load, then press ⟳. SGH only lists releases already on the agency's website. Adobe leaves out releases that are Hidden or Rejected. Shutterstock lists only active model releases.

Shutterstock says "Session expired"

Log in to Shutterstock again (Settings → Credentials → Test login session), then press ⟳.

A red "Missing: …" chip

That release is no longer on the agency's list, for example because it was deleted or hidden there. Remove the chip and pick another release.

A Getty release is greyed out

The reason is shown next to it. Usually the model profile in Release Manage needs more details.
